# 使用说明

这是本地防冲动原型。正式使用需要先配置属于你的核验公钥，参见仓库 README 和核验人指南。

## 启用与日常使用

保持整个构建输出文件夹完整，并选定长期位置。将核验人提供的 `authority-public.txt` 放在 `WishGuard.exe` 同目录。
双击程序，在“守护设置”选择是否跟随游戏，然后点击“开启 600 抽守护”。启用后规则与联动选择固定。

游戏应使用简体中文、键鼠、窗口化或无边框模式。打开限定祈愿页后停手，确认遮挡能出现。点击游戏原有的右上角 `×` 返回，识别到普通游戏画面后撤下遮挡。

程序不会替你按 Escape 或操作游戏。若未取得键盘焦点，界面会提示；此时不能认为键盘输入已被挡住。

## 自动读数

`纠缠之缘 + floor(原石 / 160)` 是当前可用抽数，不是累计收入。
例如 96,000 原石和 0 纠缠之缘，或 80,000 原石和 100 纠缠之缘，都满足 600 抽。
不计相遇之缘、创世结晶、星辉、未领取奖励或未来收入。

遮挡先出现，自动读数随后进行。两次一致读数才更新资源。看不清或卡池类型不能确认时保留旧值，并显示上次成功时间；请不要把旧值当成当前实时余额。
OCR 可能出错，因此读数本身不能直接解除守护。

## 达标后永久解除

1. 自动读数达标后导出核验申请。
2. 将申请和当前资源截图私下交给你选定的核验人，可遮住 UID。不要公开到 GitHub Issue。
3. 核验人确认当前原石和纠缠之缘后签发 `.wishpass`。
4. 在签发后七天内导入凭证。成功接受后解除永久有效，无需续期。

此时停止识别、移除自己的登录计划任务和旧启动项，启动器也会退出；以后启动原神不再带起本程序。
项目作者不提供公共签发服务。签发私钥丢失时可通过冷静期提前结束。

## 游戏联动

开启联动后，程序建立名为 `WishGuard-…` 的当前用户登录计划任务，登录约十秒后启动轻量等待进程，每两秒检查游戏是否运行。任务使用普通用户权限，不保存密码，配置了失败重试；任务注册不可用时使用登录启动项作为后备。
检测到原神后开启主程序和 OCR；游戏退出后停止 OCR，主程序约六秒后退出。
等待进程继续运行直到计划结束；它不截图、不运行 OCR。

点关闭按钮时，正在守护的主窗口收进托盘。双击托盘图标重新打开。
移动安装文件夹后，请先退出旧位置的进程，再手动打开新位置的程序，以更新启动路径。
如果开机后没有托盘图标，请手动打开一次程序，并检查 `%LOCALAPPDATA%\WishGuard\events.jsonl` 中的 `startup_registered`、`startup_fallback`、`watcher_started` 或 `startup_error` 记录。

## 提前结束与撤销

设置中可申请 24 小时冷静期。期间继续守护，关闭游戏或重启不会取消倒计时。
“撤销申请，继续守护”会清除本次提前结束申请。再次申请从完整 24 小时重新开始。
等待结束后仍须点击停止按钮，才停止守护和自动启动。

## 数据与恢复

程序数据在 `%LOCALAPPDATA%\WishGuard`；模拟环境使用 `WishGuard-Demo`，测试可以用 `--data` 指定独立目录。
正式运行不会保存或上传截图，日志不记录 OCR 原文。不需要密码、Cookie、authkey 或账号登录。
损坏或丢失已启用的状态会按锁定处理，并保留异常文件；联系你的核验人协助。

这是可被本机管理员改变的本地约束，不能作为不可绕过的安全边界。视觉识别存在延迟和兼容性限制；没有官方授权或零封号保证。
